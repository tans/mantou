# 小学英语约15秒短集生产规则

2026-10-25用户要求：每单元2–3集，每集约15秒，开头设计冲突或创意留住观众。四年级Unit 5为首个落地样本。新社媒视频以本规则为默认；普通教材母版继续按原流程归档。

## 一集的任务

一集只解决一个生活问题或一个可回答的天气/活动选择题。单元选编2–3个适合独立观看的点，不以短片覆盖全单元为目标。标题说明孩子正在遇到的问题，年级/单元继续保留作定位信息。

| 时间 | 观众看到与听到的内容 | 制作要求 |
| --- | --- | --- |
| 0–2秒 | 已经发生的问题、反常识提问或二选一；原有英语对白同时开始 | 首帧就是人物和场景，问题标题叠在首镜；避免先读栏目名/单元标题 |
| 2–10秒 | 尝试、阻碍、行动或一句目标表达 | 让英语承担情节功能；猜题留约1秒，再用角色台词揭晓 |
| 10–15秒左右 | 解法、反转或明确答案 | 每集独立兑现开头问题；答案出现在本集，不靠“下集揭晓”拖延 |
| 最后0.5–1秒 | 尾音及必要的答案停留 | 按真实音频留尾；系列编号提示另有内容，避免长关注口播占用时长 |

13–17秒为“约15秒”的制作窗口，目标15秒。先减少知识点、长停顿和包装；不得为了硬凑秒数截断对白。需要提速时使用既有明确选定的保音高参数，并在逐集清单记录；较短内容以自然语速给观众思考时间。首轮先验证内容和声音，再作发布决策。

## 脚本与素材

1. 先核对教材与既有课次脚本；逐集写清开场问题、目标句、情节推进、答案和所选范围。原文、角色替换、删改与编辑提示分别标注。
2. 角色沿用已固定的外观和声线。可复用动画/TTS先复用；确需新动作再按原教材动画流程生成，不能把局部重剪描述为新增动画。
3. 每个编辑问题/答案卡分配独立ID，标记是否有语音。无语音编辑卡不能作为教材台词进入TTS；英文和中文文案在逐集脚本中核对。
4. 发生天气/季节切换时用明确的比较提示，避免把不同情境误导为同一天突然变天。天气示例不冒充实时预报。
5. 按实际音频、静音区间和帧边界制作时间轴；保留全部词音、源文件、源SHA、裁剪区间和速度。不把源动画末帧延长声称为新动作。

## 可复现合成

每课保存版本化的`short-series-vN.json`、逐集脚本/分镜、SRT和assembly JSON。配置描述源母版/逐句时间轴/脚本、选句、编辑卡、标题和输出名。现有片头片尾包装版不作为输入；采用有原始语音的无烧录字幕普通母版，避免重复提速、重复加字幕。

```bash
python3 scripts/compose_short_series.py --config projects/<教材>/<课次>/short-series-vN.json --dry-run
python3 scripts/compose_short_series.py --config projects/<教材>/<课次>/short-series-vN.json
```

仅重做一集可加`--episode ep02`；原输出存在时使用新版本名。脚本只剪本地素材，没有TTS/视频供应商调用。沿用`compose_vertical_lesson.py --theme black --preset-version 2`，固定黑底、原比例动画和大字号双语字幕；问题标题使用既有首镜叠字能力。可编辑规范文件与渲染状态分开保存。

## 交付与后续比较

- 交付2–3条MP4、逐集SRT、首帧封面、实际片长、逐句与镜头映射、源/输出SHA、生成方法和视听检查边界。每集抽查首帧、字幕切换、答案与最后一帧，完整解码与播放；发音、音量、自然度和同步需要完整人工听检。
- 标题/简介草案围绕本集冲突或猜题，注明教材年级单元与集数；每集的封面应能单独看懂问题。平台话题须发布时从真实建议选择，草稿不等于已设置标签。
- 需要用户当前请求明确授权才向平台提交。提交后分别记录审核、公开可见与实际数据，不将“导出完成”当作“已发布”。
- 发布后在相同观察窗口分别看2秒跳出、平均观看时长、5秒留存（平台提供时）、完播和互动/收藏。记录流量规模及分发差异；先比较开头和节奏，后决定是否扩大到其它单元。样本不足或尚未发布时不宣称策略已经提高流量，也不预设保量指标。
