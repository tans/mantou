# 小学英语短视频包装与收尾流程

适用：抖音等社媒栏目片头、中文童声关注提示，以及用户明确要求的加快语速。用户于2026-10-23指定本流程：中文童声读“课本英语跟我学”，结尾读“关注我，学习更多小学英语”，提速同时保证完整收尾。

## 固定输入

- 课文来自该课已核实的脚本、无烧录字幕横屏母版和双语SRT；保留普通教材母版。
- 栏目包装使用 [`assets/branding/primary-english-child-zh-v1/profile.json`](../assets/branding/primary-english-child-zh-v1/profile.json)，声音与文字依据在同目录脚本/manifest。
- profile固定正文1.2倍、中文包装音频已做1.1倍保音高处理。更换语速用 `--speech-speed`；只收紧停顿不算完成“加快语速”。
- 新课直接复用已归档的中文童声WAV；输入文字和WAV的SHA必须与profile一致。合成过程不调用TTS或视频供应商。

## 执行

1. 核对目标课程和版本。包装文案是用户指定的补充旁白，单独登记，教材正文不改词。对源配音的发音疑点先逐句核对，保留旧版，返修时仅重配受影响行并同步登记替换母版。
2. 从横屏母版执行以下命令，使用未占用的新版本文件名。不要输入已经加过片头/片尾或已提速的交付版。

   ```bash
   python3 scripts/compose_vertical_lesson.py \
     --input projects/<教材与年级>/<课次>/renders/<无烧录字幕横屏母版>.mp4 \
     --srt projects/<教材与年级>/<课次>/edit/<双语字幕>.srt \
     --grade '小学英语 · 四年级上册' --unit 'Unit 2' \
     --title 'My friends' --lesson "A. Let's talk" \
     --theme black --preset-version 2 --tighten-pauses \
     --packaging-profile assets/branding/primary-english-child-zh-v1/profile.json \
     --output projects/<教材与年级>/<课次>/renders/<课次>-spoken-bookends-black-vN.mp4
   ```

   当前采用黑底主题：片头、片尾、标题和字幕卡同步改色；横屏母版补边应在新课配置中设 `background_color: black`。保留动画原有场景颜色；历史白底用 `--theme white` 重建。

3. 脚本先检测长静音并收紧中间空白，再用同一速度调整视频PTS和音频atempo，字幕同时映射。不会通过改采样率升高音调，也不截断对白凑时长。
4. 开场中文、英语正文、结尾中文分段播放，配音不互相覆盖。各段时长按实际完整音频向上取整到24fps帧边界；正文额外留0.25秒，关注提示额外留至少0.6秒。片尾文字保留到最后一帧，音频通过补静音对齐画面；完整保留最后一句和结尾字音。
5. 保存MP4、同名JSON、完整时间轴SRT以及`.body.srt`正文字幕。完整SRT含单行中文包装cue和双语正文cue；正文SRT保持六句之类的实际教材行数。JSON保存源指纹、静音裁剪映射、真实语速、包装profile/音频SHA及各段起止时间。修改布局或包装只重合成，不重生成教材镜头。

**生成完成条件：** 输出存在且可解码；真实音视频时长覆盖全部语音；正文文本与已核实源一致；开头和结尾有真实中文语音；语速参数真实生效；未覆盖任何旧版。

## 收尾与复核

1. `ffprobe`核对帧尺寸、fps、编码与音视频总长，FFmpeg完整解码。确认最后SRT cue持续至画面末尾，关注提示语音结束后至少保留0.6秒画面；不要用任一较短输入的结束时间裁掉配音。
2. 从实际导出的MP4分别提取开场、正文和片尾音频做反向转写。中文使用多语ASR，英语使用英语ASR；核对开场全文、最后一句英语和完整关注提示，定位疑点后与源WAV交叉核对。机器转写只是筛查，疑点和返修原因留在报告里。
3. 抽查首镜、中文转英语、正文切换、最后一句、关注提示及最后一帧。最后字幕和关注提示保持完整，不发生语音叠加。
4. 完整播放并听检：童声感、中文可懂度、提速后英语清晰度、音量差、切换点和尾音。机器解码/ASR、人工听检、用户验收分别记状态；没有完成听检时明确交付为预览并保留待验收。
5. 更新课次README、素材索引和Issue，在main提交、推送。长期复用通过项目技能入口触发本文件，不写入个人记忆文件。

## 包装文字或声音返修

只改正文课程时复用固定童声。改包装文字/声音时按[资产说明](../assets/branding/primary-english-child-zh-v1/README.md)建立新profile版本，保留合成原件、逐句输入、拆分点、处理参数和新SHA，再重合成受影响课次。片头或片尾的实际时长变化时，由音频自动重算时间轴，不能继续硬套旧秒数。
