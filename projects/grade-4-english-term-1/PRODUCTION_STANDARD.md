# 教材动画生产标准

本标准供每课、每镜头复用。完整执行入口是项目[教材动画制作技能](../../.agents/skills/textbook-video-production/SKILL.md)；新课从 [LESSON_TEMPLATE.md](LESSON_TEMPLATE.md) 建立课次记录。教材决定教学内容，用户指令决定本项目要求；分镜、角色图和生成模型只提供画面参考。

多课次统一排期或局部返修时，另按[小学教材视频批量制作指南](../BATCH_PRODUCTION_GUIDE.md)管理批次清单、费用、依赖、失效范围和恢复方式。课次 README 与素材 manifest 记录详细证据；看板只做批次概览。修改某一源文件后只重做依赖图中的后代，未受影响且已核验的节点继续复用。

## 每课制作流程

按以下顺序制作。每一步都把可复用素材保存到课次目录，并在课次 README 更新状态、文件路径和核对结论。流程不等待例行的用户确认；素材由制作方逐步整理和生成，交付供用户检查。遇到阻塞时记录阻塞原因、已完成的独立工作、受影响步骤和恢复条件；可以继续的步骤继续做，依赖项未解决的步骤保留未完成状态。

### 来源核对与阻塞记录

- 开始制作前先检查项目 README、课次 README 中已维护的教材链接及本地归档文件。核对出版社、版次/年份、年级、册次、单元和页码，不能仅按“人教版/PEP”或搜索摘要认定版本。
- 先查指定教材清单和官方教材/配套资料。清单未列目标册时，明确记录查过的链接和未收录结论，再使用可访问的扫描页或转录继续查证。每项来源注明官方原件、本地归档、第三方扫描或二手转录；记录 URL、页码和交叉核对范围。第三方来源不可称为官方原件。
- 逐句标记核实状态和证据。扫描图、分镜、模型生成结果不能替代教材原文证据；看不清的文本、未确认的角色/合读方式及互相冲突的信息标记为 `UNRESOLVED`，并列出依赖它的素材步骤。
- 缺少原版 PDF、配套音频、API 凭据或其他必要输入时，在课次 README 和对应 manifest 写明“已完成/未完成/受阻”、查找或检查结果、不会继续的依赖操作及恢复条件。不要把 dry-run、参数准备、健康检查或外观推测记为真实素材生成或验收完成。

### 1. 确定对话和旁白

- **落盘**：`script/dialogue-v1.md` 是脚本唯一来源。为所有对白和旁白分配稳定行号；逐句写明说话人、文本、教材页码/位置、原文或改编状态及证据。旁白写出完整文案并标为“补充旁白”，记录教材依据。
- **完成标准**：列出所有计划说出的内容；教材对白逐字核对，无法辨认或尚未查明的行标 `UNRESOLVED` 并记录待查证据。不把模型生成内容当教材原文，也不把未核实行用于 TTS 或依赖它的镜头。
- 来源不清时，先检查已维护的教材地址和归档资料，再通过官方资料、教材页面图像、相邻页面交叉查证；仍无法核实的内容保留未解决状态并说明阻塞范围，不猜写，也不等待例行确认。第三方扫描只作为有明确标注的临时核对依据。

### 2. 确定角色

- **落盘**：`characters/character-bible-v1.md`，列出角色 ID、名称/称呼、台词行号、出场镜头、外观与服装要点、参考图路径及来源；为每个说话角色记录持久化配音配置，包括服务商/模型、voice ID 和默认语气；同时引用 `assets/characters/voice-library.md` 中的全局 profile ID。
- **完成标准**：脚本中的每个说话人和出场角色均有映射；后续续配沿用角色库的 voice ID 和默认语气，变更时保留旧版并记录原因与生效范围；不确定设定标出依据与差异，不覆盖归档原图。旁白应有独立音色配置，不得冒充角色已核定的声线。

### 3. 生成 Storyboard

- **落盘**：`storyboards/storyboard-v1.md` 与本课分镜图/源文件。每格记录镜头 ID、脚本行号、场景、景别、动作、角色、构图、预计时长和转场。
- **完成标准**：覆盖脚本中需呈现的内容，镜头顺序明确；每格能回溯到脚本行和角色设定。Storyboard 图片或源文件放在本课目录，不放在全局素材目录。

### 4. 生成 TTS

- **落盘**：每句 TTS 输入文本保存为与脚本行号一致的 `script/tts-input/<line-id>-vN.txt`，内容必须与脚本行完全一致；每句音频保存为 `audio/tts/<line-id>-vN.wav`；`audio/manifest-v1.md` 记录脚本行号、音色、语气、模型、文件、时长、格式和 SHA-256。
- **完成标准**：只合成已核实或明确标注的脚本行；逐条试听并核对文字、发音、语速、停顿和角色声线。失败/未核实项保留状态，不得伪装成完成。
- **凭据阻塞**：调用前确认本机已配置所需凭据，不输出或提交凭据。缺少凭据时，可准备逐句输入、选择拟用音色并执行 dry-run；在 manifest 标记“等待本机配置凭据”，不调用供应商、不生成 WAV，也不将 TTS 步骤标为完成。

### 5. 分镜生成

- **落盘**：每镜使用 `shots/<shot-id>/prompt-vN.txt`，同目录记录参考图与参数；视频结果及 JSON 元数据放入课次 `renders/`。
- **完成标准**：提示词关联 Storyboard 镜头 ID、角色 ID 和脚本行号；dry-run 核对参数后提交任务，保留每版结果，不覆盖旧稿。下载后用 `ffprobe` 或等效媒体探针检查真实视频/音频流、分辨率和时长，不能只依据请求参数认定已静音。
- **意外音轨**：若请求未生成音频而原稿仍包含音轨，保留供应商原稿，另存只含视频流的派生稿；记录原稿与派生稿路径、SHA-256 和处理方式，不覆盖原文件。后续静音镜头和粗剪使用已验证无音轨的派生稿。

### 6. 字幕制作与合成

- **落盘**：`edit/subtitles-vN.srt` 保存字幕源；`edit/assembly-vN.md` 记录每个字幕 cue 对应的脚本行号、字幕模式及合成参数。
- **完成标准**：字幕逐字来自已核实脚本，标点、大小写、缩写和人名正确；时间轴根据最终音频时长与实际说话节奏制作，不以镜头目标秒数代替。逐句检查字幕不缺漏、不重复、不串序，分行自然并处于画面安全区。
- **交付模式**：用户未指定时，主预览/成片默认采用烧录字幕，确保播放器开箱可见；保留可编辑 SRT。用户需要可开关字幕或无障碍轨时，再提供软字幕轨或 sidecar。若同时提供两种模式，字幕文字和时间码必须来自同一 SRT。
- **合成验收**：烧录版抽取首/中/尾及字幕切换帧，检查拼写、对比度、换行、安全边距及是否遮挡人物/教学物件；软字幕版用 `ffprobe` 验证字幕流。完整播放核对对白同步和字幕末尾，记录字幕源、模式、视频参数和 SHA-256。

### 7. 合并

- **落盘**：`edit/assembly-v1.md` 记录镜头顺序、剪辑点、音频/字幕映射和导出参数；成片保存到 `renders/<lesson-id>-final-vN.mp4`。
- **完成标准**：所有入片素材路径明确；核对镜头顺序、对白与 TTS 同步、字幕显示、音量、转场和总时长，并记录成片 SHA-256 及待修项。烧录字幕可作为主视频；按需求一并保留软字幕版本。用户需要竖屏时，使用技能中的 `vertical-bilingual-white-v2` 和 `scripts/compose_vertical_lesson.py`，保持横屏动画源比例并用白底承载顶部课程标题与适合手机阅读的大字号双语字幕。

教材、角色图、Storyboard 和模型输出都是制作参考；教学内容以教材原文为准，改编和补充旁白要标明身份与依据。

## 每镜头生成要求

- 为镜头建立独立目录，按 `prompts/<shot-id>-vN.txt` 保存纯提示词。提示词变更就递增版本，不覆盖旧版。
- 固定比较基线：同一提示词版本、时长、画幅、分辨率、参考图集合和静音要求。供应商不支持的参数标成“不可控”，不要宣称完全同条件。
- 每个结果使用唯一文件名，禁止覆盖已有稿。
- 保存视频旁的 JSON 元数据及生成记录：供应商、模型、任务 ID、提示词文件/版本、参考图、分辨率、时长、种子/步数（若可用）、结果 SHA-256、生成日期和失败/退款状态。
- 对每版人工看片并按下方量表打分；只把通过核查的镜头标为候选成片。

## 输出命名

`<lesson-id>-<shot-id>-<provider>-<model>-<resolution>-<duration>-vN.mp4`

提示词使用相同的 `<lesson-id>-<shot-id>-vN.txt` 命名。供应商名和参数写入文件名及旁边元数据，原始生成稿不覆盖、不手工修剪后冒充模型原稿。

## 质量检查量表

每项 0–5 分，并记录可观察到的问题：

| 维度 | 检查点 |
| --- | --- |
| 教学准确 | 情境、物件和动作符合教材；对白原文无误。 |
| 分镜表达 | 主体、景别、动作和镜头顺序清楚。 |
| 角色连续 | 发型、服装、年龄感、颜色和角色关系稳定。 |
| 画面质量 | 清晰度、构图、光线、背景和细节可用。 |
| 动作稳定 | 人体/物件结构合理，运动连续，无明显闪变或穿帮。 |
| 声音可用 | 发音、对白、口型和背景音符合目标（静音镜头标 N/A）。 |

对比报告必须同时列出量表、关键缺陷和推荐理由；分数用于团队内部筛选，不代表客观模型排名。出现教材内容错误、角色错误、对白与配音不符或明显生成瑕疵时，即使总分高也不能通过。

## 课次复用

每个新单元从本标准复制课次清单和镜头记录模板，替换教材来源、语言点、角色和场景；保留提示词版本、参数记录、质量量表与人工复核步骤。不得把上一课的角色动作或对白直接当作新课教材内容。
