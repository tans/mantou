# 教材动画生产标准

本标准供每课、每镜头复用。新课从 [LESSON_TEMPLATE.md](LESSON_TEMPLATE.md) 建立课次记录。教材决定教学内容，用户指令决定本项目要求；分镜、角色图和生成模型只提供画面参考。

## 每课开工资料

- 课程身份：教材版本、册次、单元、课时、目标年级和目标语言点。
- 教材依据：页码、原文对白、目标词句及核对人/日期；改编对白要标注改编原因。
- 镜头清单：镜头 ID、地点、出场角色、动作、对白、预计秒数、转场和对应分镜格。
- 角色与场景：引用已归档设定图；新课新增设定时先入对应 `assets/` 并记录来源。
- 制作约束：画幅、画风、对白语言、字幕策略、配音策略、供应商及成本上限（如用户提供）。

## 每镜头生成流程

1. 先核教材内容和分镜顺序，再写镜头简报；画面提示词不得替代或改写教材对白。
2. 为镜头建立独立目录，按 `prompts/<shot-id>-vN.txt` 保存纯提示词。提示词变更就递增版本，不覆盖旧版。
3. 先固定比较基线：同一提示词版本、时长、画幅、分辨率、参考图集合和音频要求。供应商不支持的参数标成“不可控”，不要宣称完全同条件。
4. 先用 dry-run 核对参数；确认后提交生成任务。每个结果保留唯一文件名，禁止覆盖已有稿。
5. 保存视频旁的 JSON 元数据及生成记录：供应商、模型、任务 ID、提示词文件/版本、参考图、分辨率、时长、种子/步数（若可用）、结果 SHA-256、生成日期和失败/退款状态。
6. 对每版人工看片并按下方量表打分；只把通过核查的镜头标为候选成片。

## 输出命名

`<lesson-id>-<shot-id>-<provider>-<model>-<resolution>-<duration>-vN.mp4`

提示词使用相同的 `<lesson-id>-<shot-id>-vN.txt` 命名。供应商名和参数写入文件名及旁边元数据，原始生成稿不覆盖、不手工修剪后冒充模型原稿。

## 质量检查量表

每项 0–5 分，并记录可观察到的问题：

| 维度 | 检查点 |
| --- | --- |
| 教学准确 | 情境、物件和动作符合教材；对白原文无误。 |
| 分镜表达 | 主体、景别、动作和镜头顺序清楚。 |
| 角色连续 | 发型、服装、年龄感、颜色和角色关系稳定。 |
| 画面质量 | 清晰度、构图、光线、背景和细节可用。 |
| 动作稳定 | 人体/物件结构合理，运动连续，无明显闪变或穿帮。 |
| 声音可用 | 发音、对白、口型和背景音符合目标（静音镜头标 N/A）。 |

对比报告必须同时列出量表、关键缺陷和推荐理由；分数用于团队内部筛选，不代表客观模型排名。出现教材内容错误、角色错误或明显生成瑕疵时，即使总分高也不能通过。

## 课次复用

每个新单元从本标准复制课次清单和镜头记录模板，替换教材来源、语言点、角色和场景；保留提示词版本、参数记录、质量量表与人工复核步骤。不得把上一课的角色动作或对白直接当作新课教材内容。
