# 教材动画生产标准

本标准供每课、每镜头复用。新课从 [LESSON_TEMPLATE.md](LESSON_TEMPLATE.md) 建立课次记录。教材决定教学内容，用户指令决定本项目要求；分镜、角色图和生成模型只提供画面参考。

## 每课制作流程

按以下顺序制作。每一步都把可复用素材保存到课次目录，并在课次 README 更新状态、文件路径和核对结论。流程不等待例行的用户确认；素材由制作方逐步整理和生成，交付供用户检查。

### 1. 确定对话和旁白

- **落盘**：`script/dialogue-v1.md` 是脚本唯一来源。为所有对白和旁白分配稳定行号；逐句写明说话人、文本、教材页码/位置、原文或改编状态及证据。旁白写出完整文案并标为“补充旁白”，记录教材依据。
- **完成标准**：列出所有计划说出的内容；教材对白逐字核对，无法辨认或尚未查明的行标 `UNRESOLVED` 并记录待查证据。不把模型生成内容当教材原文，也不把未核实行用于 TTS 或依赖它的镜头。
- 来源不清时，继续通过教材页面图像、相邻页面和归档资料查证；仍无法核实的内容保留未解决状态并说明阻塞范围，不猜写，也不等待例行确认。

### 2. 确定角色

- **落盘**：`characters/character-bible-v1.md`，列出角色 ID、名称/称呼、台词行号、出场镜头、外观与服装要点、参考图路径及来源。
- **完成标准**：脚本中的每个说话人和出场角色均有映射；不确定设定标出依据与差异，不覆盖归档原图。

### 3. 生成 Storyboard

- **落盘**：`storyboards/storyboard-v1.md` 与本课分镜图/源文件。每格记录镜头 ID、脚本行号、场景、景别、动作、角色、构图、预计时长和转场。
- **完成标准**：覆盖脚本中需呈现的内容，镜头顺序明确；每格能回溯到脚本行和角色设定。Storyboard 图片或源文件放在本课目录，不放在全局素材目录。

### 4. 生成 TTS

- **落盘**：每句 TTS 输入文本保存为与脚本行号一致的 `script/tts-input/<line-id>-vN.txt`，内容必须与脚本行完全一致；每句音频保存为 `audio/tts/<line-id>-vN.wav`；`audio/manifest-v1.md` 记录脚本行号、音色、语气、模型、文件、时长、格式和 SHA-256。
- **完成标准**：只合成已核实或明确标注的脚本行；逐条试听并核对文字、发音、语速、停顿和角色声线。失败/未核实项保留状态，不得伪装成完成。

### 5. 分镜生成

- **落盘**：每镜使用 `shots/<shot-id>/prompt-vN.txt`，同目录记录参考图与参数；视频结果及 JSON 元数据放入课次 `renders/`。
- **完成标准**：提示词关联 Storyboard 镜头 ID、角色 ID 和脚本行号；生成静音视频。dry-run 核对参数后提交任务，保留每版结果，不覆盖旧稿。

### 6. 合并

- **落盘**：`edit/assembly-v1.md` 记录镜头顺序、剪辑点、音频/字幕映射和导出参数；成片保存到 `renders/<lesson-id>-final-vN.mp4`。
- **完成标准**：所有入片素材路径明确；核对镜头顺序、对白与 TTS 同步、字幕、音量、转场和总时长，并记录成片 SHA-256 及待修项。

教材、角色图、Storyboard 和模型输出都是制作参考；教学内容以教材原文为准，改编和补充旁白要标明身份与依据。

## 每镜头生成要求

- 为镜头建立独立目录，按 `prompts/<shot-id>-vN.txt` 保存纯提示词。提示词变更就递增版本，不覆盖旧版。
- 固定比较基线：同一提示词版本、时长、画幅、分辨率、参考图集合和静音要求。供应商不支持的参数标成“不可控”，不要宣称完全同条件。
- 每个结果使用唯一文件名，禁止覆盖已有稿。
- 保存视频旁的 JSON 元数据及生成记录：供应商、模型、任务 ID、提示词文件/版本、参考图、分辨率、时长、种子/步数（若可用）、结果 SHA-256、生成日期和失败/退款状态。
- 对每版人工看片并按下方量表打分；只把通过核查的镜头标为候选成片。

## 输出命名

`<lesson-id>-<shot-id>-<provider>-<model>-<resolution>-<duration>-vN.mp4`

提示词使用相同的 `<lesson-id>-<shot-id>-vN.txt` 命名。供应商名和参数写入文件名及旁边元数据，原始生成稿不覆盖、不手工修剪后冒充模型原稿。

## 质量检查量表

每项 0–5 分，并记录可观察到的问题：

| 维度 | 检查点 |
| --- | --- |
| 教学准确 | 情境、物件和动作符合教材；对白原文无误。 |
| 分镜表达 | 主体、景别、动作和镜头顺序清楚。 |
| 角色连续 | 发型、服装、年龄感、颜色和角色关系稳定。 |
| 画面质量 | 清晰度、构图、光线、背景和细节可用。 |
| 动作稳定 | 人体/物件结构合理，运动连续，无明显闪变或穿帮。 |
| 声音可用 | 发音、对白、口型和背景音符合目标（静音镜头标 N/A）。 |

对比报告必须同时列出量表、关键缺陷和推荐理由；分数用于团队内部筛选，不代表客观模型排名。出现教材内容错误、角色错误、对白与配音不符或明显生成瑕疵时，即使总分高也不能通过。

## 课次复用

每个新单元从本标准复制课次清单和镜头记录模板，替换教材来源、语言点、角色和场景；保留提示词版本、参数记录、质量量表与人工复核步骤。不得把上一课的角色动作或对白直接当作新课教材内容。
